Какие данные собираем

  • Email и хэш пароля (bcrypt) для аккаунта
  • Настройки обучения: цель, уровень CEFR (A1–C1)
  • Прогресс по словам, статистика сессий и streak
  • Технические события (свайпы, завершение сессии) — без содержимого паролей
  • Реферальный код и факт регистрации по приглашению

Напоминания (push)

Если вы включаете напоминания, мы дополнительно храним подписку браузера на push-уведомления (endpoint и ключи шифрования), выбранное время напоминания и часовой пояс. Отключить напоминания можно в любой момент в настройках приложения — после этого данные подписки удаляются.

Как используем

Данные нужны только для работы приложения: авторизация, SRS, streak, статистика, напоминания и реферальная программа. Мы не продаём данные третьим лицам.

Хранение и защита

Данные хранятся на управляемых облачных базах данных (Postgres / Redis). Пароли — только в виде хэша (bcrypt). Сессии — в httpOnly cookie; все запросы к API защищены CSRF-токенами и передаются по HTTPS. Предпочтение темы (светлая / тёмная / система) хранится только в браузере на вашем устройстве и на сервер не отправляется.

Ваши права

Вы можете самостоятельно удалить аккаунт со всеми данными (прогресс, сессии, статистика) безвозвратно: Настройки → «Удалить аккаунт». Также доступен сброс прогресса без удаления аккаунта (Настройки → «Сбросить статистику и прогресс»). По вопросам обработки данных пишите в поддержку проекта.
