# LangSwipe — Site / Product Specification

> **Проект:** PWA для изучения лексики  
> **Кодовое имя:** LangSwipe (Swipe Vocab)  
> **Версия спеки:** 1.2  
> **Дата:** 2026-10-03  
> **Код:** `package.json` **0.5.15** · прод https://www.langswipe.xyz

**Текущий продукт:** три учебные пары с русским интерфейсом — турецкий (A1–C1), английский (A1–C1), испанский (A1–B2). Язык выбирается в онбординге и в настройках; прогресс по каждой паре хранится отдельно. Стек — Vite + ванильный JS на клиенте, Express на сервере, Neon Postgres (JSONB) в проде.

---

## 1. Видение продукта

Приложение для изучения лексики с механикой «Tinder для слов»: быстрый triage известных/неизвестных слов через свайп, глубокое изучение через тапы по карточке. Главная цель — **не превратить изучение слов в рутину**.

### Ключевая механика

| Действие | Поведение |
|----------|-----------|
| Свайп влево | Слово известно → увеличить интервал SRS, убрать из активной очереди |
| Свайп вправо | Слово неизвестно / хочу учить → сброс интервала, очередь повторений |
| Тапы по карточке | Перевод, произношение (TTS), примеры, часть речи, формы глагола |
| Конец сессии | Короткий итог: слова на повтор, streak, достижения |

### Anti-routine (как в коде)

- Сессия **18 карточек** (`SESSION_SIZE` в `server/session.js`), не бесконечная лента
- Смесь **новых (~70%) и повторений (30%)**
- Уровень CEFR копит предыдущие (`levelsUpTo`); пустой дек при полном «Знаю» → предложение повысить уровень
- Streak общий на аккаунт. Если до сброса осталось **меньше 3 часов**, на значке ⚠️; нажатие показывает время сброса (`src/streak-risk.js`)
- Вариативность форматов карточек (слово → аудио → мини-фраза) — ещё не сделано

## 2. Что уже в продукте

- Языковые пары: **TR→RU, EN→RU, ES→RU**; словари из CSV в `server/data/`
- Онбординг: имя, язык, цель (путешествия / работа / экзамен), уровень CEFR; экран «кабинет создаётся»
- Лендинг со свайп-колодой преимуществ
- Карточка слова: touch + mouse
- Оверлей: перевод, TTS языка словаря, примеры, часть речи, формы глагола
- SRS: упрощённый SM-2 (`server/srs.js`)
- Auth: email + пароль, удаление аккаунта
- Кабинет секциями: главная, настройки, статистика
- Прогресс: streak, сессии, ETA уровня, достижения по языку (streak общий)
- Уровень вверх с итога сессии, статистики или отдельного экрана
- Тема: система / светлая / тёмная
- PWA: манифест, установка, офлайн-экран «Нет интернета»
- Web Push-напоминания (QStash), время выбирает пользователь
- Реферальная ссылка
- Кружок по пересечению словаря: до 8 человек одного языка, подбор по общим словам, приглашение ссылкой, сессия по пересечению
- «Что нового» (`src/changelog.js`)
- Админ-дашборд, еженедельный отчёт D1/D7
- Юридические страницы и FAQ

### Вне продукта

- Склонения (формы глагола в оверлее уже есть)
- Пользовательские колоды и импорт
- Нативные iOS/Android (только PWA)
- AI-репетитор
- Отмена последнего свайпа
- Hard mode: ввод перевода

## 3. Пользовательские сценарии

### US-1: Первая сессия

1. Пользователь задаёт имя, язык, цель и уровень
2. Получает дек до 18 слов
3. Свайпает / открывает оверлей
4. Видит итог сессии и при необходимости достижения

### US-2: Повторение

1. На следующий день дек смешан: повторы due + новые слова текущего CEFR
2. SRS обновляет интервалы после каждого свайпа
3. Если серия под угрозой (< 3 ч до сброса), главная показывает предупреждение

### US-3: Глубокое изучение

1. Тап по карточке: перевод, аудио, примеры, формы глагола
2. Свайп вправо или влево после просмотра

### US-4: Смена языка

Прогресс и бейджи за слова остаются у своей пары. Streak не сбрасывается.

## 5. Метрики

| Метрика | Цель |
|---------|------|
| D7 retention | ≥ 25% — порог, после которого план открывает социальный слой |
| Карточек за сессию | 18 |
| Средняя длина сессии | 3–7 мин |

Отчёт: `npm run report:weekly`. Живые цифры: `/admin/dashboard.html`.

## 6. Технический стек (как в репозитории)

| Слой | Выбор |
|------|-------|
| Frontend | Vite 6, ванильный JS (`src/app.js`), CSS |
| Backend | Express (`server/index.js`), serverless entry `api/index.js` |
| БД | Neon Postgres, документ `langapp_state` JSONB. Приоритет: Postgres → Redis → файл. Словарь в Postgres не пишется |
| SRS | Упрощённый SM-2, `server/srs.js` |
| TTS | `GET /api/tts` + Web Speech на клиенте |
| Слова | CSV → `server/import-vocabulary.js`, id стабильны через `_wordIdMap` |
| Auth | bcrypt, cookie-сессия, CSRF double-submit на mutating `/api` |
| Напоминания | Web Push + QStash, `server/reminders.js` |
| Deploy | Vercel, домен www.langswipe.xyz. Инструкция: `docs/DEPLOY.md` |
| Тесты | `npm test` (SRS, сессия, прогресс, milestones, reminders, admin, streak-risk) |

Исходный NEXUS-план предполагал Laravel + Livewire. Этот стек не собирался; источник правды — текущий Node-код.
