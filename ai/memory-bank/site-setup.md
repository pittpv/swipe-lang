# LangApp — Site / Product Specification

> **Проект:** веб-сервис / PWA для изучения иностранного языка  
> **Кодовое имя:** LangApp (Swipe Vocab)  
> **Версия спеки:** 1.1  
> **Дата:** 2026-09-10

**Текущий продукт:** три учебные пары с русским интерфейсом — турецкий (A1–C1), английский (A1–C1), испанский (A1–B2). Язык выбирается в онбординге и в настройках; прогресс по каждой паре хранится отдельно.

---

## 1. Видение продукта

Приложение для изучения лексики с механикой «Tinder для слов»: быстрый triage известных/неизвестных слов через свайп, глубокое изучение через тапы по карточке. Главная цель — **не превратить изучение слов в рутину**.

### Ключевая механика

| Действие | Поведение |
|----------|-----------|
| Свайп влево | Слово известно → увеличить интервал SRS, убрать из активной очереди |
| Свайп вправо | Слово неизвестно / хочу учить → добавить в учебный набор + очередь повторений |
| Тапы по карточке | Перевод, произношение (TTS), 2 примера фраз, часть речи |
| Конец сессии | Короткий итог: N слов на повтор, streak, без бесконечной ленты |

### Anti-routine (обязательные принципы UX)

- Сессия ограничена **15–20 карточками**, не бесконечная лента
- Смесь **новых (70%) и повторений (30%)** в каждой сессии
- Вариативность форматов карточек (слово → аудио → мини-фраза) — фаза 2
- Прогресс с смыслом, не vanity metrics

## 2. Scope MVP (Must Have)

### В scope

- Языковые пары: **TR→RU, EN→RU, ES→RU**; словари в `server/data/vocabulary*`
- Онбординг: имя, изучаемый язык, цель, уровень CEFR
- Карточка слова со свайпом (touch + mouse для веба)
- Тап-действия: перевод, TTS (язык словаря), примеры, часть речи, формы глагола
- SRS (интервальные повторения) под капотом
- Auth (email)
- Прогресс: streak, статистика сессии, ETA уровня; прогресс не смешивается между языками
- PWA: установка на home screen
- Словари: турецкий ~3 500, английский ~4 200, испанский ~4 000 лемм

### Out of scope (сейчас)

- Социальный матчинг / study circles
- Полная грамматика сверх форм глагола в оверлее
- Пользовательские колоды и импорт
- Нативные iOS/Android приложения (только PWA)
- AI-репетитор, чат

### Фаза 2 (после валидации D7 retention)

- Study circles по пересечению словаря
- Склонения для 1–2 языков
- Пользовательские колоды
- Push-уведомления о повторении

## 3. Пользовательские сценарии

### US-1: Первая сессия

1. Пользователь выбирает язык, цель и уровень
2. Получает дек из 20 слов
3. Свайпает / тапает по карточкам
4. Видит итог: «5 слов на повтор завтра»

### US-2: Повторение

1. Пользователь открывает приложение на следующий день
2. Дек смешан: 14 новых + 6 повторений
3. SRS обновляет интервалы после каждого свайпа

### US-3: Глубокое изучение

1. Пользователь не уверен в слове
2. Тапает: перевод → аудио → примеры
3. Свайпает вправо после изучения

## 5. Метрики успеха MVP

| Метрика | Цель |
|---------|------|
| D7 retention | ≥ 25% |
| Карточек за сессию | 15–25 |
| Средняя длина сессии | 3–7 мин |
| % свайпов вправо → «знаю» через 7 дней | ≥ 60% |

## 6. Технический стек

| Слой | Выбор |
|------|-------|
| Frontend | Laravel + Livewire + FluxUI (веб), Alpine.js для жестов свайпа |
| Backend | Laravel 11 API + Eloquent |
| БД | PostgreSQL или SQLite (dev) |
| SRS | FSRS или SM-2 (PHP implementation) |
| TTS | Web Speech API (MVP) |
| Данные слов | Kaikki / Wiktionary → ETL в собственную схему |
| Auth | Laravel Breeze / Fortify |
| Deploy | CI/CD через GitHub Actions |
| QA | Playwright screenshots: `./qa-playwright-capture.sh` |

### Ограничения разработки

- Без фоновых процессов в командах (`&` запрещён)
- Сервер разработки уже запущен — не стартовать в задачах
- Изображения: Unsplash, picsum.photos — **не Pexels**
- FluxUI: только поддерживаемые props
